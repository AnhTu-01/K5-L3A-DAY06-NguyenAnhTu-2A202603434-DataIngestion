# Ghi chú thiết lập

Chọn Python 3.11+ và cách vector hóa phù hợp. TF-IDF + cosine là baseline từ vựng có thể chạy offline; semantic embeddings qua API hoặc model local là tùy chọn. Ghi rõ model, phiên bản, setup và giới hạn; không âm thầm thay model khi backend lỗi. Nếu dùng PDF cần công cụ trích text; trang scan cần OCR hoặc đánh dấu lỗi và chọn đủ trang thay thế. Tài liệu đi qua API phải được phép chia sẻ với nhà cung cấp.
